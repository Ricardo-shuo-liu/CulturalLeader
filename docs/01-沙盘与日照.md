# 沙盘、日照与地标

全国视角的舞台：中国地图是一块可以环绕观看的**浅浮雕沙盘**，山脉真实隆起、国境实描边，
城市光点贴在真实经纬度上；场景光照由天文算法按真实时刻驱动，晨昏线会真的扫过版图。

---

## 一、操作方式

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 环绕旋转（俯仰限制在接近垂直与接近水平之间，不会转到地平面以下） |
| 滚轮 / 双指捏合 | 缩放（2.2 – 11 个世界单位） |
| 右键拖动 | 平移，范围限制在沙盘附近 |
| 悬停光点 | 光点放大，城市名浮动 |
| 单击有 3D 建模的城市 | 相机飞过去，地标升起，数字人讲解 |
| 双击任意城市 | 进入该城市的游玩流程编辑（见 [02-行程规划与攻略](02-行程规划与攻略.md)） |
| 点击省份区块 | 镜头飞入该省；省级视野才显示该省的地级市 |
| 右上时刻牌 | 展开时间滑块做日照演示，「回到实时」恢复跟随 |

URL 覆盖：`?t=2026-09-23T06:30` 或 `?t=06:30`（固定演示时刻），`?live=0`（关闭实时跟随）。

## 二、舞台构成

```
浮雕沙盘（y 轴向上）   340×196 高度场：10 条主脊真实隆起，山脊明暗随时段变化
国境描边               2.6px 实描边 + 6px 冷色外发光，省界一并绘出
城市光点               贴在浮雕表面，正对相机，按所在地真实昼夜独立亮灭
壁画地台               敦煌风格程序化壁画：联珠/卷草/忍冬纹样 + 四角藻井，
                       外圈莲花、云气与飘带，中央按沙盘轮廓掏空
地面光池               中心墨色光池 + 墨云纹理（加色混合），随时段与经度改变色调
天穹                   大球渐变背景，任何视角都不会出现纯黑
幕布（z=-13.5）        120×66 的两片对开水墨绸幕，幕上有远山剪影，夜间浮出星点
空气层                 760 颗缓慢上浮的尘埃微粒，夜间更暖更亮
地标                   点击城市后从沙盘该点升起（程序化几何，见下）
数字人（Live2D）       独立透明画布常驻右下：口型由音频包络驱动，见 04 文档
画面收边               径向暗角 + 顶部压暗，让沙盘成为视觉中心
```

参数集中在 `frontend/js/config.js`（沙盘跨度、隆起高度、相机限制、幕布尺寸），
山脊走向在 `frontend/js/data/ranges.js`，浮雕与描边生成在 `frontend/js/terrain.js`。

## 三、真实日照（实测数据）

浏览器实测（无头 Firefox，隐藏界面后按真实经纬度取样）：

| 取样点 | 06:30 | 12:00 | 23:00 | 06:30 色温 |
| --- | --- | --- | --- | --- |
| 南京附近 118.8E,32.1N | 48.2 | 36.9 | 10.6 | 暖 +6.4 |
| 天山北麓 87.6E,43.8N | 11.1 | 37.8 | 9.7 | 冷 −8.0 |

即 06:30 时东部已被金色晨光照亮、西部仍在夜色中；正午两地都亮，夜间都暗。
地图区域另有 7100+ 高亮轮廓像素与 11000+ 强边缘像素，国境线与山脉层次都清晰可辨。

日照实现：`frontend/js/solar.js` 提供太阳高度角/方位角与关键帧光照，
地形着色器逐片元按该点真实经纬度计算昼夜与色温（`frontend/js/shaders.js` 的 `SOLAR_GLSL`）。

## 四、城市标注与 3D 地标

城市标注按视野自动切换：全国尺度只显示重点城市（省会 / 首府 / 直辖市 / 特别行政区 / 旅游名城），
视野宽度小于约 1200 公里时显示该省的全部地级市；标签只放在锚点**正上方**一个位置，
整数对齐、落位粘性（不会因相机轻动在槽位间跳动），两层标签共用同一套防重叠网格。
打开城市看 3D 地标时全部地名自动收起，视角压得很低时也收起。

**有 3D 地标的 38 座城市**（全部为程序化几何，无外部模型文件）：

- **4 座直辖市**：北京（天坛祈年殿）、上海（东方明珠）、天津（天津之眼）、重庆（洪崖洞吊脚楼）
- **23 座省会**：石家庄（赵州桥）、太原（永祚寺双塔）、沈阳（沈阳故宫大政殿）、长春、哈尔滨（圣索菲亚）、
  南京（明城墙门楼）、杭州（雷峰塔）、合肥、福州（白塔）、南昌（滕王阁）、济南（超然楼）、郑州（二七塔）、
  武汉（黄鹤楼）、长沙（天心阁）、广州（广州塔）、海口（骑楼老街）、成都（天府熊猫塔）、贵阳（甲秀楼）、
  昆明（金马碧鸡坊）、西安（钟楼）、兰州（中山桥）、西宁（塔尔寺金顶）、台北（台北 101）
- **5 座自治区首府**：呼和浩特（蒙古包与大召）、南宁（会展中心）、拉萨（布达拉宫）、银川（清真寺穹顶）、
  乌鲁木齐（国际大巴扎）
- **2 个特别行政区**：香港（维港天际线）、澳门（大三巴牌坊）
- **4 座旅游名城**：洛阳（龙门石窟）、敦煌（莫高窟九层楼）、桂林（漓江喀斯特）、苏州（虎丘塔）

每座城市都带简介、讲解词与两条以上问答，可以直接问数字人。地标细节按层数反复堆叠
（反宇屋檐、斗拱、台基栏杆、格窗、檐铃、脊兽、门钉板门、瓦当、灯笼），单座通常 100–400 个几何体，
檐下另补一盏方向光，近看不会糊成一片黑。
