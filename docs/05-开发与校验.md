## 一、目录结构

```
backend/app        FastAPI（城市/对话/语音/流程/攻略/穿越/后台）+ SQLite
backend/app/data   内置数据（城市、地级市、省界、历史朝代：唐/宋/明 疆域与诗词）
backend/tests      pytest：接口、后台鉴权、Mock 降级、穿越数据与对话
frontend/js        舞台渲染、浮雕地形、天文日照、地标、语音
frontend/js/map    城内地图、城市流程、整体攻略、播放推演、穿越模式、诗词光韵
frontend/js/fay    Fay 风格数字人（Live2D 加载/口型/动作/动作语义映射）
frontend/assets/live2d  Live2D 模型与 config.json
frontend/vendor    本地 ESM 依赖（tools/vendor_frontend.py 生成，离线可用）
docs/              分类文档（本目录）
tools              依赖抓取、轮廓数据、迁移与各类校验脚本
data/              本机数据（flows / guides / imports / tts_cache / geo 缓存，不进 git）
```

## 二、环境变量（`.env`）

| 变量 | 作用 |
| --- | --- |
| `OPENAI_API_KEY` / `OPENAI_BASE_URL` / `CHAT_MODEL` | 大模型对话（城市讲解与朝代对话）；可指向 DeepSeek 等兼容网关 |
| `TTS_*` / `ASR_*` | 语音合成与识别，见 [04-语音与数字人](04-语音与数字人.md) |
| `TENCENT_MAP_KEY` / `TENCENT_MAP_SK` | 后端用：算通勤时长、搜 POI、取行政区划（WebServiceAPI） |
| `TENCENT_MAP_JS_KEY` | 浏览器地图用（JS API GL，不需要勾选任何产品） |
| `MAP_QPS` / `MAP_DAILY_LIMIT` / `ALLOW_ESTIMATE` | 限流与降级策略 |
| `MOCK_MODE` / `ADMIN_TOKEN` | 本地 Mock（`on` 时城市讲解走本地知识库）与后台令牌 |

`.env` 已在 `.gitignore` 中，任何 Key 都不会进 git；`python tools/check_map.py` 与
`python tools/check_voice.py` 会逐项验证并给出修复建议。

## 三、脚本一览

```bash
# 安装与素材
pip install -r requirements.txt          # 官方源慢可加 -i https://mirrors.aliyun.com/pypi/simple/
python tools/vendor_frontend.py          # 一次性：把 three 拉到 frontend/vendor（离线可用）
python tools/vendor_live2d.py            # Live2D 运行时（通常已随仓库提供）
python tools/fetch_live2d_sample.py --name Haru   # 换一个官方示例模型

# 数据维护（可选）
python tools/fetch_cities_cn.py          # 重新生成全国城市清单
python tools/fetch_provinces_cn.py       # 重新生成省界数据
python tools/migrate_trips.py --dry-run  # 旧行程 → 城市流程 + 整体攻略（幂等，可演练）
python tools/migrate_trips.py            # 执行迁移

# 服务
./run.sh                                 # http://127.0.0.1:8000/（端口占用会自动顺延，PORT=9000 可指定）
```

## 四、全量校验

```bash
./tools/check_all.sh                     # 后端 59 项 + 前端 35 项 + 全部 JS 语法
python tools/check_map.py                # 腾讯位置服务 Key 逐项自检（不用启动服务）
python tools/check_voice.py              # 语音合成 / 识别自检
python tools/check_live2d_model.py       # Live2D 模型是否满足接入要求

./run.sh &                               # 另开一个终端启动服务，然后跑浏览器端到端：
python tools/browser_check.py            # 沙盘 / 数字人 / 路线 / 省份点击
python tools/browser_check_flows.py      # 双击城市 → 流程编辑 → 优化 → 攻略 → 分享页（含无 Key 降级路径）
python tools/browser_check_dynasty.py    # 穿越系统：唐/宋/明 底图、光韵诗字、诗词、朝代对话
python tools/analyze_shots.py            # 截图像素统计（日照与沙盘观感回归）
```

浏览器脚本用系统自带 Firefox（无头）。本机是 snap 版 Firefox，脚本会优先使用
`/snap/firefox/current/usr/lib/firefox/` 里的 geckodriver 与浏览器二进制
（`/snap/bin` 的包装脚本在无桌面会话时会起不来）。

Node 未安装时可用便携版：`.tools/node/bin/node`（`check_all.sh` 会自动识别）。

## 五、常见问题

- **页面打开是空白 / 城市数据加载失败**：先 `python tools/check_map.py`，再看 `./run.sh` 的日志；
- **城内地图是自建矢量底图**：没配 `TENCENT_MAP_JS_KEY`，功能完整（边界、点位、路线、比例尺、指北针），
  配好 JS Key 后重启即用腾讯底图；
- **通勤时长标注「估算」**：腾讯 WebServiceAPI Key 没配、IP 未加白名单或当日配额用尽；
  按 `check_map.py` 的提示修，或接受估算继续用；
- **预约/固定时间排不进去**：单日点位过多或时间窗冲突，优化结果里会标注「已放宽 N 个时间窗」；
- **穿越对话提示未配置**：朝代对话只走大模型，按提示在 `.env` 配 `OPENAI_API_KEY` 后重启服务。
