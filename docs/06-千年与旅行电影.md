这一批改造把「六个并列模块」串成一条能看完的动线：**开场 30 秒 → 沙盘 → 一块土地的千年 →
排行程 → 导出旅行电影**。三件事都建立在既有资产上，不推倒重来。

## 一、开场：你和这片土地的故事（A1）

每次打开都会播（约 22 秒），2 秒后出现「跳过」；导航抽屉里有「重播开场」；
`?intro=0` 直接进沙盘（自动化测试用）。

五段运镜（`frontend/js/intro.js` + `frontend/js/camera_track.js`）：

1. **太空俯冲**：相机沿关键帧曲线从高空收拢，标题「你和这片土地的故事」浮起；
2. **穿云**：幕布水汽起落（复用晕影与幕布，不新建体积云）；
3. **晨昏线扫过**：舞台时间从 04:50 加速到 19:10（北京时间），日照 shader 真的扫出晨昏线；
4. **城市次第点亮**：城市光点按经度从西到东亮起（`citypoints` 的 `setReveal`）；
5. **定格与开场白**：镜头停在上次访问的城市（`localStorage.cl.lastCity`），否则西安；
   数字人用一句开场白收尾，随后回到实时日照。

## 二、一块土地的千年（A2，城市卡新入口）

穿越全景是「按朝代看全图」；**千年模式反过来**：锁定一个城市点，让两千年从它身上流过。
入口在城市卡 / 城市面板的**「千年 / 一块土地的千年」**；有 ≥2 期记载的城市都能进，
十座精选城市（西安、洛阳、北京、南京、成都、杭州、苏州、敦煌、泉州、开封）保证 11 期有内容。

### 连续的时间，而不是 11 格切换

- 时间域 **前 221 年 → 今年**，一段一段首尾相接：秦 / 汉 / 三国 / 晋 / 隋 / 唐 / 宋 / 元 / 明 / 清 / 现代；
- 底部是**连续年份滑杆**（朝代色带 + 事件刻点 + 年份刻度），可以拖、可以点、可以按 ◀▶ 跳上一朝/下一朝；
  HUD 用大字显示「公元 750 年 · 唐」，改名链（内史 → 长安 → 大兴城 → 京兆府 → 奉元路 → 西安）
  随年份高亮；
- **疆域像墨迹一样连续生长/收缩**：每期一张遮罩（清晰 + 模糊两通道），跨段 12 年混合窗里两层遮罩
  按比例融合；浮雕网格**不重建**（复用沙盘同一份几何），边界线按 160 点重采样后逐帧插值；
- **前朝残影**：走过的朝代轮廓留下同色幽灵线（默认保留最近 4 条，可开「残影全开」），
  历史是一层层叠出来的；
- **日照随年份连续插值**：唐·夏至黄昏 → 宋·秋日傍晚 → …，拖动时间轴就能看到晨昏线在走。

### 360° 环幕：坐在环形剧场中央看这座城的每一年

- **天幕圆筒**：半径 12.5（大于最大镜头距离 11，任何机位都在场内）、高 8 的环形幕布，
  天空色随日照在昼 / 晨昏 / 夜三段间切换，夜里叠星；
- **日月对齐**：太阳与月亮按**真实方位角**挂在环上、高度角决定其高度——
  地图上的晨昏线扫到哪里，环幕上的日月就在哪个方位（验收脚本会断言两者一致）；
- **三层剪影视差**（皮影戏式的层板）：远层山脊、中层城郭（墙 / 宫室 / 塔 / 市井 / 高楼，
  按年份在两个朝代的形态之间连续插值——墙在长、塔在升、楼群在起）、近层脚手架、工匠、
  驼队与船、火盆；**谁在长，谁旁边就出现脚手架与抡锤的工匠剪影**；
- **锚定城市段**：环幕的长卷固定在「地图中心 → 锁定城市」的方位上，从城市向外看，正对着它；
- **事件与建造呼应**：事件年火光与烟柱从中层升起、天幕泛光；地标建造时中层同步出现脚手架与半成的剪影；
- 顶栏可开关「**环幕**」，只在千年模式创建与销毁，不改变沙盘、开场、穿越与电影的观感。

### 地标随史建造：38 座真实模型，从脚手架里长出来

- 有模型的城市（38 座）：锁定点旁立真实地标模型（`landmarkFactory`），**城郭剪影让位**；
  其余城市保留城郭剪影（立在地层柱顶——城，建在两千年的地层上）演化；
- **分件建造**：模型构件按包围盒高度分 14 层，在史实建造窗口里逐层出现，每层落位带缩放回弹、
  尘土与建造音效（石凿 / 夯土 / 木构 / 钢构四套程序化合成），建造期间脚手架随进度升高；
- **史实年表**（`backend/app/data/millennium_landmarks.py`，38 条）：始建、重建、焚毁、开凿、天际线、
  自然常在六类语义；重建类（黄鹤楼、雷峰塔、滕王阁、甲秀楼、超然楼、金马碧鸡坊、索菲亚教堂等）
  演「建 → 残迹 → 原址重建」，焚毁类（澳门大三巴 1835）演到残迹为止；
  `gap` 字段区分「毁后待重建（ruins）」与「迁建 / 扩建 / 天际线（keep）」——钟楼 1582 年是迁建，
  空档期照旧在场，不会被误演成废墟；
- 接口：`GET /api/dynasty/millennium?...&landmark_key=bell_tower` 返回 `landmark: {key, kind, phases}`。

### 地层柱、时间之尘、事件与解说

- **3D 地层柱**：锁定点升起一柱考古剖面，一层一朝代，**层厚 = 朝代实际年数**（秦 15 年薄薄一层、
  宋 372 年厚厚一层），点击任意一层直接跳年；
- **时间之尘**：拖动得越快，光尘越亮——时间在流动这件事变得可见；
- **事件年表**：十座城市各 8–10 条史实事件（`backend/app/data/millennium_events.py`），
  跨过事件年份时弹出书法事件卡（年份 + 标题 + 一句话），点开可以追问当朝人；
- **解说开关**：打开后，跨过事件年数字人会以当朝人口吻念一句解说词（6 秒冷却）；
- **▶ 千年一刻**：约 45 秒从 -221 跑到今天，镜头绕锁定点缓缓环绕上升，
  逐条念出解说词，末尾收一句总结——一座城的两千两百年被讲成一部小纪录片；
- **跨朝音效**：早段编钟、后段石磬（全部程序化合成），环境音随「古代 / 帝制 / 近代」三段演变。

### 数据与接口

后端 `backend/app/data/millennium.py` + `millennium_events.py`：**不改动既有朝代数据**，只做聚合与策展。

```
GET /api/dynasty/millennium?name=西安&lng=108.94&lat=34.34
→ { counts, featured, bounds{start,end,blend_years}, bands[11], headline, events[],
    eras[11]{ key, name, period, color, lighting, persona, matched, source,
              place{ancient,modern,kind_label,summary,narration…}, poems, note } }
```

逐期匹配顺序：**今名精确 → 今名前缀（西安 → 西安阎良）→ 策展补注 → 60km 内最近地名**，
`source` 如实标注；空档给出「此朝疆域未及此地」或「此朝此地暂无记载」。
每朝在 `dynasties.py` 的 `MILLENNIUM_META` 里各有一条当朝人设与代表时刻；
对话接口的 `anchor` 会把「锁定点 + 当期古名 + 正在拖时间轴」写进提示词。

## 三、旅行电影（A3 轻量版）

入口：**我的攻略 → 导出旅行电影**。把整份攻略渲染成一段 30–60 秒的 WebM：

1. **脚本编译**（`buildMovieScript`，纯函数）：按天生成日卡、点位字幕与旁白文案（模板生成，不走大模型）；
2. **沙盘拍摄**：相机按天飞过攻略里的城市，地标升起（带尘土粒子），
   每到一个城市把舞台时间切到当天第一站的时刻——晨昏线随行程扫过；
3. **合成与录制**：叠加画布逐帧合成「沙盘画面 + 电影黑边 + 日卡 + 字幕 + 封尾卡（行程概览 + 分享二维码）」，
   `captureStream(30)` 与 WebAudio 混音流一起交给 `MediaRecorder(vp9/vp8, opus)`；
4. **声音**：TTS 旁白逐句解码后按时间轴调度；配乐优先用 `/api/config` 清单里的古琴素材，
   没有素材就用程序化古琴；
5. **封尾二维码**：`GET /api/guides/{id}/share-qr.png`（首次导出会自动生成只读分享 token）。

导出是**实时录制**（约等于脚本时长），完成后可以页内回看与下载；
浏览器不支持 `MediaRecorder / captureStream` 时会明确提示改用 Chrome / Edge。

## 四、语音与环境音（本次一并修掉的两个问题）

### 云端优先，禁用 espeak

- 云端 TTS 就绪时（`/api/config` 的 `tts_ready`），**永不退回系统语音**——
  Linux 上的 espeak 念中文是逐字拼读、像在念字母，那是「声音不对」的根源；
- `VoiceIO.unlock()`：首次用户手势（任意 pointerdown）解锁音频图，
  之后 `audio.play()` 不再被自动播放策略拦截；
- 开场句若在任何手势之前被拦截：先出字幕 + 提示「点一下页面任意处，语音就来了」，
  第一次点击后**自动补播**（不会静音丢句、也不会换成机器人声）；
- 云端完全不可用时才保留系统语音兜底，并明确标注音质。

### 环境音不再产生 404

- 服务端在 `/api/config` 下发 `ambience` 清单（扫描 `frontend/assets/audio/`，风/水/古琴三个槽位）；
- 前端按清单加载，缺文件直接用程序化合成（风/水噪声、Karplus-Strong 古琴、编钟/石磬/whoosh），
  **不再逐个探测 URL**；
- 把 CC0 音频放进 `frontend/assets/audio/`（`wind` / `water` / `guqin`，支持 webm/ogg/mp3）
  即自动优先使用，并请在 `THIRD_PARTY_LICENSES.md` 登记来源。

## 五、皮相

- **字体**：标题与卡片统一走衬线字体栈（优先系统里的 `Noto Serif CJK SC`，OFL 许可）；
- **配色**：石青 / 朱砂 / 赭石三个矿物色变量，千年时间轴、地层、事件卡都取这些颜色；
- **转场**：卡片与事件卡用水墨晕染（`inkReveal`）；换期用水汽 veil；
- **微交互**：地标升起回弹 + 尘土粒子；城市光点呼吸；时间之尘随拖动速度亮起。
