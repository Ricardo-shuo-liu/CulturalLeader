# 行程路径规划使用说明

沙盘负责全国视角（市级标注 + 跨市路线），点城市进入**行程工作台**用真实地图做城内逐日编排。
每天去哪由你自己决定，系统负责算通勤、排顺序、按开放时间与固定预约优化。

## 〇、先自检（推荐第一步）

```bash
python tools/check_map.py     # 不需要启动服务，直接读 .env 并调用腾讯位置服务接口验证
```

它会逐项检查「行政区划 / POI 搜索 / 路径规划」是否可用、JS Key 是否配置，
并把腾讯返回的 status 码翻译成可执行的修复建议（例如 311 = Key 格式错误、
120 = 当日配额用尽、110/112 = 来源或 IP 未被授权、111 = 需要填 SK 签名）。
界面里也能点：行程工作台右上角「环境自检」，结果会写在工作台左下角的结果区。

## 一、准备：填腾讯位置服务 Key（可选，不填也能用）

在项目根目录建 `.env`（可复制 `.env.example`）：

```ini
# 后端用：勾选「WebServiceAPI」的 Key（不要外泄到浏览器）
TENCENT_MAP_KEY=你的WebServiceKey
# 该 Key 若开启了签名校验，把 SK 填这里（控制台可查看），否则留空
TENCENT_MAP_SK=
# 浏览器地图用：另建一个勾选「Web端(JS API)」的 Key，并在授权域名里填 127.0.0.1 与线上域名
TENCENT_MAP_JS_KEY=你的JS_Key

MAP_QPS=3             # 每秒最大请求数（限流）
MAP_DAILY_LIMIT=5000  # 每日调用上限（超过后自动降级为估算）
ALLOW_ESTIMATE=true   # 是否允许降级估算（false 时超配额直接报错）
```

创建 Key 的步骤：<https://lbs.qq.com/> → 控制台 → 应用管理 → 我的应用 → 添加 Key：
- **必需**：勾选 **WebServiceAPI**（后端用：路径规划、POI 搜索；可配置授权 IP）→ `TENCENT_MAP_KEY`
- **可选**：再建一个 Key，**不勾选任何产品**——腾讯官方文档明确写着
  「Javascript API GL 并不需要勾选任何产品，直接创建 Key 就可以使用」→ `TENCENT_MAP_JS_KEY`
  （只有这个 Key 才会把城内地图换成腾讯地图底图；没有它就用内置离线矢量底图，功能完整）

> 控制台里能勾选的服务类型只有 **WebServiceAPI / SDK / 微信小程序** 三种是对的：
> `SDK` 是给 Android/iOS/Unity 客户端用的，本项目不需要。

> **只有 WebServiceAPI 也能完整使用**：后端照常算通勤时长与 POI；
> 浏览器里的城内地图改用**离线矢量底图**（自动拉取该市的区县边界并缓存到 `data/geo/`），
> 支持滚轮缩放、拖拽平移、每段里程/耗时标注与比例尺，不需要 JS Key。
> 若以后拿到「Web端(JS API)」的 Key，填上 `TENCENT_MAP_JS_KEY` 就会自动切换成腾讯地图底图。

改完 `.env` 后**重启服务**（`Ctrl+C` 再 `./run.sh`），然后 `python tools/check_map.py` 应全部 PASS。
**没有 Key 也能完整跑通**：系统用直线距离×道路系数估算（步行 4.5km/h、驾车 28km/h、公交 22km/h），
结果里会明确标注「估算」，工作台右上角显示「示意图（未配置 JS Key）」。

## 二、操作流程

0. **打开导航**：左上角「☰ 导航」打开侧边抽屉，分四块独立区域（互不遮挡，可逐个点击）：
   **行程**（打开行程规划 / 路线规划）、**城市与省份**（城市搜索 / 跳到省份）、
   **显示与声音**（画质 / 静音）、**时间与日照**（时刻牌 + 滑块 + 回到实时）。
   不打开导航时，画面上只有城市标注与数字人。
1. **沙盘上找城市（按视野自动切换，不需要手动选）**：
   - **全国尺度**（视野宽度 ≥ 约 1200 公里）：只显示**重点城市**（直辖市/省会/计划单列市，约 33 个）；
   - **缩进到省级范围**（视野 < 约 1200 公里）：自动显示**落在视野内的所有地级市**并带名字，
     也就是"进到这个省才看到这个省的城市"；
   - 在导航里的搜索框输入城市名回车，会直接飞到该城市并进入省级视野
     （例：飞入洛阳后视野约 283 公里，显示郑州、三门峡、南阳、安阳等 17 个城市）；
   - **想直接看某个省**：导航里「城市与省份 → 跳到省份」选择省份后点「飞到该省」，
     或在沙盘上直接点击该省区域，镜头会按该省范围自动取景；
   - 进入省级视野后，沙盘会淡入**省界**与**省名**，画面不再只有地名与黑底。
2. **点城市 → 城市卡片 →「进入城市规划」**，打开行程工作台。
3. **逐日编排**：顶部「第 N 天」标签切换/新增天数；每天可设出行方式（步行/打车/公交）、优化目标
   （结束最早 / 通勤最短）、出发与结束时间、出发点名称（酒店/车站，默认用当天城市中心）。
4. **加点位**：
   - 右上搜索框按关键词搜索（如「兵马俑」），结果里点「加入当天」；
   - 或点时段按钮（早餐/午餐/咖啡/晚餐/夜宵/小店/打卡）看**附近推荐**，一键加入。
5. **排序**：
   - 手点「重新优化」→ 调用 LKH-3.0.14 的 TSPTW，按真实通勤时长 + 开放时间/固定预约求最优顺序；
   - 或**在地图上长按点位拖动**，拖到目标位置松手即插入该位置（列表里的 ↑↓ 也可以），
     手动调整后点「重新优化」可再次求解，**锁定的点会保持位置**。
6. **点位详情**：点击点位或列表行，可改停留时长（默认 60 分钟）、设「固定时间」（如 14:00 的预约）、
   锁定、删除、或设为当天出发点。
7. **结果**：左侧显示求解器、出发→结束时间、通勤/等待分钟数、逐点到达时间；地图上按天配色画 polyline
   与编号标记；数字人会播报「今天几个点、预计多久」。
8. **导出/导入**：工作台右上角可把行程导出为 JSON，或导入别人给的 JSON（导入会另存为新行程）。

## 三、逐日与跨城

- 一天归属一座城市；点地图上另一座城市时，若当天已有安排，会自动**新增一天**给你那座城市。
- 城际段（前一天城市 → 当天城市）可选驾车/公交或手动填时长，只在沙盘上作提示连线，不参与城内排序。
- 想按"给定天数 + 想去的城市"自动生成草案属于后续功能，当前版本由你自己决定每天去哪。

## 四、接口一览（给二次开发用）

| 接口 | 说明 |
| --- | --- |
| `GET /api/geo/cities` | 全国城市清单（名称/省份/中心坐标/层级） |
| `GET /api/trips`、`POST /api/trips`、`GET|PUT|DELETE /api/trips/{id}` | 行程的增删改查 |
| `POST /api/trips/import` | 导入行程 JSON（自动换新 id） |
| `POST /api/trips/{id}/days/{day}/optimize` | 单日排序：`{mode, objective, start, end, keep_locked}` |
| `GET /api/poi/search?keyword=&city=` | 关键词搜索 POI |
| `GET /api/poi/around?lng=&lat=&bucket=&radius=` | 附近推荐（时段分桶） |
| `GET /api/poi/{poi_id}` | POI 详情（含营业时间） |
| `GET /api/map/status` | 配额用量、缓存条数、是否降级 |
| `GET /api/map/selftest` | 逐项自检（行政区划/POI/路径规划/JS Key） |
| `GET /api/config` | 前端公开配置（仅 JS Key） |

错误契约：`409 MAP_KEY_MISSING`（未配 Key 且禁止估算）、`429 MAP_QUOTA_EXCEEDED`、
`502 MAP_UPSTREAM_ERROR`（上游异常，均会回退估算并标注）。

## 五、缓存与配额

- 所有腾讯位置服务调用只走后端，浏览器只拿 JS Key 加载地图。
- 结果缓存进 SQLite（表 `map_cache`）：POI 7 天、路线 3 天、行政区划 30 天；重复优化命中缓存，不重复扣配额。
- 每日调用计数写入 `map_quota` 表，`GET /api/map/status` 可查看；达到上限后自动降级估算。

## 六、数据与文件

- 行程存本地文件：`data/trips/<trip-id>.json`（原子写），列表索引 `data/trips/index.json`。
- 城市清单：`frontend/js/data/cities-cn.js`，由 `python tools/fetch_cities_cn.py` 生成
  （有腾讯 Key 时走行政区划接口，否则走 DataV 公开数据）。
