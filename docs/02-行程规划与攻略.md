# 行程规划与攻略

> 相关文档：[01-沙盘与日照](01-沙盘与日照.md)（怎么看沙盘）· [03-穿越系统](03-穿越系统.md)（朝代模式）·
> [04-语音与数字人](04-语音与数字人.md)（数字人怎么说话）· [05-开发与校验](05-开发与校验.md)（脚本与自检）

沙盘负责全国视角（省级区块、市级标注、跨市连线），**双击任意城市**进入该城市的
**游玩流程编辑**（真实可拖拽的腾讯地图），把多座城市的流程组合起来就是一份**整体攻略**。
本文件覆盖：多城市巡游求解、腾讯 Key 配置、流程编辑、抄作业导入、播放推演、整体攻略、接口与数据。

## 〇、先自检（推荐第一步）

```bash
python tools/check_map.py     # 不需要启动服务，直接读 .env 调用腾讯位置服务接口验证
```

逐项检查「行政区划 / POI 搜索 / 路径规划 / JS Key」，并把腾讯返回的 status 码翻译成修复建议
（311 = Key 格式错误、120 = 当日配额用尽、110/112 = 来源或 IP 未授权、111 = 需要填 SK 签名、121 = 配额包用尽）。
界面里也能点：流程编辑右上角「环境自检」。

## 〇之二、巡游路线（多城市 LKH 求解）

沙盘（或「☰ 导航 → 路线规划」）进入多选模式：点城市加入或移除，选好后点「求解最优路线」，
后端把选中城市写成 TSPLIB GEO 实例并调用**本地 LKH-3.0.14** 求最短巡回，
结果以金色航线画在地图上（带流动光点），并按顺序给城市编号，数字人播报总里程与顺序。

- 求解器位置：`LKH-3.0.14/LKH`；若不存在会自动退回内置「最近邻 + 2-opt」并在界面标注。
- 重新编译：`make -C LKH-3.0.14`（需要 gcc/make）。
- 距离口径：LKH 用 TSPLIB GEO（先纬度后经度），显示里程用 haversine，两者已交叉校验
  （五城示例：LKH 5044 km vs haversine 5036 km，误差 0.2%）。

这条「城市级巡回」与下面的「城内流程编辑」是两层：巡游回答"先去哪座城"，
流程编辑回答"这座城里一天怎么走"。

## 一、准备：两个腾讯位置服务 Key（都可以不填）

```ini
# 后端用：勾选「WebServiceAPI」的 Key，并把这台机器的出口公网 IP 加进白名单
TENCENT_MAP_KEY=
TENCENT_MAP_SK=            # 该 Key 开了签名校验才填，否则留空
# 浏览器用：再建一个 Key，什么都不勾选（JS API GL 不需要勾选任何产品）
TENCENT_MAP_JS_KEY=

MAP_QPS=3                  # 每秒最大请求数
MAP_DAILY_LIMIT=5000       # 每日调用上限，超过后自动降级为估算
ALLOW_ESTIMATE=true        # 是否允许降级估算
```

- 出口 IP 不确定？`python tools/check_map.py` 会直接打印「本机出口公网 IP」。
- **只填 WebServiceAPI 也能完整使用**：城内地图自动用自建矢量底图
  （该市行政区边界 + 点位 + 路线 + 比例尺 + 指北针，同一套 Web Mercator 投影，拖拽/缩放/双击放大都支持）。
- 只填 JS Key 不填 WebServiceAPI：底图是腾讯地图，但通勤时长是估算值（界面标注「估算」）。
- 强制走降级底图排障：打开 `http://127.0.0.1:8000/?map=canvas`。

## 二、沙盘交互（点哪个、双击哪个）

| 操作 | 结果 |
| --- | --- |
| **双击任意城市**（含重点城市） | 进入该城市的**流程编辑**（自动定位到该城） |
| 单击有 3D 建模的城市（**38 座**，见下） | 地标模型升起 + 讲解词 + 数字人播报（面板里还有「规划这座城市」按钮可直接进流程编辑） |
| 单击其他城市 | 浮动卡片（省级/地级市 + 坐标），卡片上「进入流程编辑」按钮 |
| 点击省份区块 / 导航里选省份 | 镜头飞入该省（省级视野才显示该省城市） |

城市标注按视野自动切换：全国尺度只显示约 33 个重点城市；视野宽度 < 约 1200 公里时
显示落在视野内的该省全部地级市（带城市名）。导航里的搜索框输入城市名回车即可飞过去。

## 三、流程编辑（双击城市后进入）

顶栏：返回沙盘 · 流程名（可改）· 所属城市 · 同城流程下拉 · 新建 · 另存副本 · 导出 / 导入 · 删除。

左侧：

1. **出行方式**：步行 / 打车 / 公交（影响通勤时长与排序结果）。
2. **优化目标**：「结束最早」（含营业时间与固定预约，默认）或「通勤最短」。
3. **出发点（起点）有三种选法**，侧栏里都有：
   - **在地图上点选起点**：点按钮进入点选模式，然后在真实地图上点一下，那一点就成为出发点（**不会新增点位**）；
   - **用第一个点位**：把列表第一个点位当起点；
   - **回到城市中心**：起终点都改回城市中心；
   列表里每个点位还有一个小小的 **「起」** 按钮，点一下就把它设为起点；选好后侧栏会显示「出发点：名称（经纬度）· 出发时间」。
4. **点位列表**：↑↓ 调序、**起**（设为出发点）、🔒 锁定（重新优化时保持位置）、✕ 删除，点击看详情。
5. **点位详情**：停留时长（默认 60 分钟）、固定时间（如 14:00 的预约）、营业时间、设为出发点、移除。
6. **重新优化**：调用 LKH-3.0.14 的 **TSPTW**（时间窗来自营业时间/固定时间，服务时长=停留时长），
   用腾讯真实通勤时长算矩阵；配额不足或无 Key 时自动降级估算并在结果里标注。

右侧地图：

- **连续拖拽**平移、**滚轮/双指**缩放、**双击**放大，右上角**指北针**（点击回到全览）、左下角**比例尺**；
- **在地图上点一下**（任意位置）会弹出「在这里加一个点位」小卡片：名字自动取最近的地点（逆地理编码），
  改好名字点「加入流程」即可；卡片上还有 **「设为出发点」**（把这里当起点、不加进点位）与 **「取消」**——
  取消就是纯粹取消，不会偷偷加点位，也不会再弹一次；
- 点位在地图上显示为编号标记（起/终 + 名称），点标记看详情，长按标记可拖拽调序；
- **路线连线**随时可见：按当前顺序连成一条线；「重新优化」之后，每一段上还会浮出
  「X 分钟 · Y km（估算）」的小标签，一眼就能看出整天的走法和通勤时间；
- 长按点位 **400ms** 进入拖拽，松手插入到最近路段（列表里的 ↑↓ 同效）；
- 搜索框按关键词搜 POI（如「龙门石窟」），或点「早餐/午餐/咖啡/晚餐/夜宵/小店/打卡」看**附近推荐**，
  一键「加入流程」；
- 地图上按顺序画 polyline、编号标记、每段「分钟 · 公里（估算）」标注。

优化完成后数字人会播报「这条流程几个点、预计多久、几点到几点」。

## 三之二、规划时也能和数字人说话

进入流程编辑（或「我的攻略」）后，**数字人会跟着进到面板右下角**，同一套语音与口型照常工作，
左下角还有一个「问数字人」小面板：

- 输入问题回车或点发送，数字人会朗读回答，文字同时留在面板里；
- 「按住说话」同样可用（走的是同一套语音识别）；
- 面板上方会显示「正在讲解：城市名」，会跟着你切换城市流程自动更新；
- **没收录讲解资料的城市也能问**：后端会按城市名继续回答，并说明本地资料有限，不会硬编内容；
- 省会 / 自治区首府 / 直辖市 / 特别行政区（含台北）都已有讲解与问答，问这些城市能直接拿到专属答案。

## 三之三、抄作业：把别人的攻略导进来

导航 →「我的攻略」→「导入攻略（抄作业）」：

1. **粘贴来源**：链接 / 正文 / 截图（可多张）。小红书、抖音等需要登录的站点抓不到正文时会提示改用后两条；
   截图解析需要 `OPENAI_API_KEY`。
2. **预览勾选**：按天分组列出「地点 / 时间 / 停留时长 / 是否已定位」，可勾选、改名、改时长；改城市会按新城市重新定位。
3. **地图确认**：左边是真实地图，右边是待定位清单，点「在地图上定位」再点地图即可落位，已定位的点实时出现在地图上。
4. **生成**：一键产出「一城一天一个计划块」+ 一份草稿攻略；点任意计划块即可进真实地图编辑、调序、重新优化。

规则解析会把「Day1/第一天」切天，「上午/下午/晚上」与 `09:00` 这类时间切时段，`·、→、/` 切地点，
自动去掉营销话术与表情；识别不到坐标的点保留为「待定位」，不会丢内容。

## 三之四、播放推演（把行程放一遍）

计划块头部「▶ 播放这一天」进入推演模式：

- **旅行者光点**按 `plan.timeline` 推进：出发 → 逐段通勤（显示分钟/公里/方式）→ 抵达 → 停留 → 离开 → 收尾，
  已走过的路径会高亮；城内点位距离很近，所以地图上主要看光点在点位之间移动，细节都在右侧日志里。
- **昼夜层 + 晨昏线**按当前模拟时刻与视野经纬度实时计算叠加在地图上：夜侧半透明墨蓝、
  晨昏线附近一条暖色暮光线；时钟每前进 2 分钟（或地图移动）重绘一次。沙盘幕布与时间牌同步到模拟时刻。
- **播放条**：播放/暂停、1×/2×/4×/8×（1× = 每秒 6 模拟分钟）、拖动进度条跳站、上一站/下一站、
  跟随镜头（默认开，手动拖地图即解除）、数字人播报（默认关）、退出推演（默认回到实时，可勾选「保持时刻」）。
- **多天连续推演**：「我的攻略 → ▶ 播放整份攻略」按天切换城市地图；跨城显示「前往成都 · 驾车 6h40m · 620km」过渡卡并 4× 快进
  （最长 6 秒），过夜显示「夜间休整 13h」并固定约 2 秒快进到次日 09:00，过渡期间昼夜层继续推进。
- 某天未优化时会自动先优化一次（失败会提示并跳过该天）；推演本身**不修改任何数据**，退出后仍可正常编辑保存。

## 四、整体攻略（导航 →「我的攻略」）

1. 左侧**流程库**列出所有城市流程（城市 · 点位数 · 结束时间），点「加入下一天」逐天组装；
2. **攻略逐日**里可上移/下移/替换成另一条流程/删除，并给每天写备注；
3. 右侧汇总：**总天数、总里程、总时长**，以及每天「城市 · 点位数 · 结束时间 · 里程 + 城际段耗时」；
   城际段（上一座城市 → 下一座城市）优先用腾讯驾车路线，失败时用直线估算并标注「估算」；
4. 「重新计算」保存并重算；「导出 JSON」导出攻略；「分享链接」生成只读分享页 `/share/<token>`；
5. 「数字人播报」让数字人朗读「几天、途经哪些城市、总里程、总时长」。

## 五、接口一览（二次开发用）

| 接口 | 说明 |
| --- | --- |
| `GET/POST /api/flows`、`GET|PUT|DELETE /api/flows/{id}` | 城市流程增删改查（`?city=` 可按城市筛选） |
| `POST /api/flows/{id}/duplicate` | 另存为副本 |
| `POST /api/flows/{id}/optimize` | 单流程排序：`{transport, objective, day_start, day_end, start, keep_locked}` |
| `POST /api/flows/import` | 导入流程 JSON（自动换新 id） |
| `GET/POST /api/guides`、`GET|PUT|DELETE /api/guides/{id}` | 攻略增删改查（PUT 传 items 会重算城际段与总计） |
| `POST /api/guides/{id}/share` | 生成只读分享 token（页面 `/share/{token}`，数据 `/api/guides/shared/{token}`） |
| `POST /api/guides/{id}/flows/{flowId}?day=N` | 替换某一天的流程 |
| `GET /api/geo/cities` / `provinces` / `city-boundary` | 城市清单 / 省份 / 城市行政边界（矢量底图用，带磁盘缓存） |
| `GET /api/poi/search`、`/api/poi/around`、`/api/poi/{id}` | POI 搜索、附近推荐（时段分桶）、详情 |
| `GET /api/poi/reverse?lng=&lat=` | 地图取点：给任意坐标配一个可读名字（无 Key 时返回「地图取点 + 坐标」，永不失败） |
| `GET /api/map/status`、`/api/map/selftest`、`/api/config` | 配额状态、逐项自检、前端公开配置（仅 JS Key） |

错误契约：`409 MAP_KEY_MISSING`、`429 MAP_QUOTA_EXCEEDED`、`502 MAP_UPSTREAM_ERROR`，均回退估算并标注。

两点变化：

- 静态图接口 `/api/geo/static-map` 与其磁盘缓存已删除——城内地图现在是可连续拖拽的腾讯 GL 地图，
  无 Key 时用自建矢量底图，不再需要「一张静态截图」的方案；
- 旧的「行程工作台」升级为「城市流程编辑」，数据由 `/api/flows` 承载；`/api/trips*` 仅作为旧数据兼容保留，
  请用 `python tools/migrate_trips.py` 把旧行程迁移成流程与攻略（迁移幂等，原文件保留）。

## 六、数据与迁移

- 城市流程：`data/flows/<flow-id>.json` + `data/flows/index.json`（原子写）；
- 整体攻略：`data/guides/<guide-id>.json` + `data/guides/index.json`；
- 两个目录都在 `.gitignore` 里（属于本机数据，不进 git）。

从旧的 `data/trips/*.json` 迁移（按城市拆成流程 + 一条攻略，**幂等**，默认保留原文件）：

```bash
python tools/migrate_trips.py --dry-run     # 先看会拆出多少流程/攻略
python tools/migrate_trips.py               # 执行
python tools/migrate_trips.py --cleanup     # 顺带把原行程挪到 data/trips/_migrated/
```

## 七、缓存与配额

- 所有腾讯位置服务调用只走后端，浏览器只拿 JS Key 加载地图；
- 结果缓存进 SQLite（表 `map_cache`）：POI 7 天、路线 3 天、行政区划 30 天，重复优化不重复扣配额；
- 每日调用计数写入 `map_quota`，`GET /api/map/status` 可查看，达到上限后自动降级估算。
