# ui_marker_spot_done

- Category: ui
- Size: 32×56
- Colors used: 13 from InkGongbi48 (asset budget 16)
- Animation: none
- Design notes:
  - 已访 marker：同一石灯，灯室熄灭（INK3/INK2），无暖光。
  - 右下加盖朱砂印（VERMILION + VERMILION_D），印面为负形门形符号，作为打卡完成的识别锚点。
  - 与未访 marker 共用轮廓与基座，保证并排/切换时位置稳定。
- Variants: 未访帧见 `ui_marker_spot_idle_0/1`。
